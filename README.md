# Spotify Web Player Clone

A Spotify-inspired Web Player homepage recreated using **HTML and CSS**
as part of my frontend development learning and practice.

The project focuses on reproducing a desktop music-streaming interface
with navigation, a library sidebar, music sections, album cards, footer
links, and a bottom music player.

## Features

-   Spotify-inspired desktop Web Player interface
-   Top navigation with Home, Search, Browse, Explore Premium, Install
    App, Notifications, Listening Activity, and Profile
-   Your Library sidebar with playlist and podcast sections
-   Music category filters: All, Music, and Podcasts
-   Getting Started section
-   Recommended music section
-   Popular albums and singles section
-   Shows section
-   Music cards with cover artwork, song title, artist information, and
    hover play button
-   Horizontal scrolling music-card sections
-   Footer with company, community, useful links, and Spotify plans
-   Social media icons
-   Bottom music player UI with current song information, playback
    controls, progress bar, volume control, and additional controls
-   Hover effects and tooltips

## Technologies Used

-   HTML5
-   CSS3
-   Font Awesome
-   Google Fonts --- Montserrat

## Responsiveness

The current version is primarily designed for **laptop/desktop
screens**.

It is **not fully responsive for mobile and tablet devices yet**. Some
responsive CSS has been explored, but complete mobile and tablet
adaptation is planned as a future improvement.
